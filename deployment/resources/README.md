# CityChat implementation resources

Artifact v0.6.1 is the implementation example layer for approved normative CityChat VES v0.6. The versioned records below govern this team-learning artifact; they do not create VES v0.6.1 authority or enable a product capability.

- `starter/` — minimal token-bound StoryCell specimen that developers can copy into a prototype.
- `citychat-ves/v0.6.1/citychat-color-role-map.json` — generated CityChat colour-usage overlay on the pinned LDS `color-srgb-05` source; not a second palette or analytical scale.
- `citychat-ves/v0.6.1/citychat-icon-map.json` — closed functional-icon roles and capability gates.
- `citychat-ves/v0.6.1/citychat-icon-resolution.json` — actual local controls that may use an icon, plus explicitly blocked bindings.
- `citychat-ves/v0.6.1/font-assets.manifest.json` — exact self-hosted Material Symbols Rounded subset, axes, source, hash and licence record.
- `citychat-ves/v0.6.1/semantic-motion.citychat.yml` — inherited LDS motion primitives or deliberate `none`, with reduced-motion and no-JavaScript outcomes.
- `../qa/automated.v0.6.1.json` and `../qa/rendered-local.v0.6.1.json` — artifact-specific source and rendered validation records; they do not certify CityChat product runtime.
- `../site-manifest.v0.6.1.json` — exact release file inventory and rollback lineage for this artifact.
- `../implementation-notes.v0.6.1.md` — human-readable artifact change and release boundary.
- `../assets/downloads/citychat-visual-experience-specification-v0.6.md` — approved CityChat first-value, living-city identity, civic-continuity, motion, composition, and implementation guide.
- `../assets/downloads/citychat-ves-v0.6-approval.json` — exact normative approval record and scope.
- `../assets/downloads/citychat-ves-playground-release-authorization.v0.6.1.json` — release authorization for this exact implementation artifact.
- `../assets/identity/identity-assets.v0.6.1.json` — exact-build, URL, role, theme, backdrop and surface approvals for CityChat identity artwork.
- `../build-card.v0.6.1.yml` and `../control-inventory.v0.6.1.json` — artifact truth/delivery boundary and rendered-control inventory.
- `../assets/downloads/citychat-product-experience-profile-v0.4.md` — full product experience contract.
- `../assets/downloads/citychat-build-card-template.yml` — start every artifact by resolving its truth and delivery boundary.
- `../assets/downloads/citychat-component-contracts.v0.4.json` — machine-readable CityChat component and state registry.
- `../assets/downloads/vibe-coding-prompt.md` — prompt scaffold for a development assistant.
- `../vendor/landometer/v0.9.0/` — byte-identical upstream Landometer machine package snapshot.

The vendored upstream package is immutable. Update it only by pinning a new approved Landometer release and regenerating all downstream evidence. The icon gallery is a teaching reference: reply, share, history, receipt, CityScan and officer icons stay non-operational until their owning product capabilities are separately evidenced and enabled.
