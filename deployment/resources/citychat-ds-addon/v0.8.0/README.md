# CityChat DS Add-on implementation records v0.8.0

This directory contains the small, artifact-specific records used by the CityChat DS Add-on Playground v0.8.0.

Current frontstage and public-download identity is CityChat-only. The pinned LDS vendor snapshot is an immutable dependency and may contain other upstream product profiles; those files are not CityChat assets and do not grant rendering or reuse permission.

- `citychat-color-role-map.json` maps CityChat jobs to the pinned Landometer `color-srgb-05` roles. It does not create a second palette.
- `font-assets.manifest.json` pins the exact Google Material Symbols Rounded subset, static axes, source, file hash and Apache-2.0 notice.
- `citychat-icon-map.json` is the closed functional-icon role map for this artifact. Library-only roles do not enable product capabilities.
- `citychat-icon-resolution.json` binds only truthful local teaching/document controls and records blocked or capability-gated uses separately.
- `semantic-motion.citychat.yml` maps CityChat teaching interactions to existing LDS motion tokens or to `none`.
- `citychat-button-contract.json` makes the capsule-or-circle rule testable for people and code generators.
- `cityscan-hero-specimen.html` is a downloadable place-first hero example with an honest no-score fallback.
- `cityscan-citycell-taxonomy.json` normalizes exactly three owner-directed viewport prompts—**แถวนี้น่าอยู่ยังไง**, **น่าเที่ยวตรงไหน**, and **น่าค้าขายอะไรดี**—and their CityCell groups without creating an overall score.
- `citychat-case-library.json` connects `LIVE-01`, `VISIT-01`, and `TRADE-01` across scan, citizen, and officer lenses. `REJECT-01` documents why one aggregate CityScore is not allowed.
- `../../../assets/asset-library.v0.8.0.json` lists every safe public-download asset with its exact path, MIME type, byte size, SHA-256, source, licence or rights reference, allowed uses and blocked uses.

These records govern this team-learning artifact only. They do not enable CityChat runtime capabilities, approve additional identity assets, define analytical scales, or supersede Landometer DS or owning product/data sources. Every example place, value, response, handoff, checklist and status is a local conceptual fixture. The working taxonomy is conceptual; draft rating, count, ADR, and category placements are not approved metrics or observed values. Unknown or unresolved evidence is not zero.

Download access never transfers an asset into a new runtime role. The library intentionally excludes personal photos, avatars, screenshots, user-generated content, real-location media, uncleared working documents and unclear-rights files.
