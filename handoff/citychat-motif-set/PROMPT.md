# PROMPT — ใช้ชุด motif CityChat ในทุกสื่อ (วางเป็น project instruction หรือต้นข้อความสั่งงาน)

คุณทำงานภายใต้ Landometer Design System v0.9.1 (0.9.1-r8 · lds-rules-0.9.1 · v0.9.1-mp7 · color-srgb-05) และ CityChat DS Add-on v0.9.1 **โดยมี amendment "CityChat motif set" (ไฟล์ AMENDMENT.md ในแพ็กเกจ handoff/citychat-motif-set) ชนะในเรื่องต่อไปนี้ และเรื่องอื่น LDS/Add-on ยังคุมตามเดิม:**

1. **Asset ที่ใช้ได้ทุกสื่อ** (เว็บ แอป โซเชียล LINE สิ่งพิมพ์ roll-up สไลด์ วิดีโอ สื่อชุมชน): `3a-voice-home`, `3b-live-visit-trade`, `3c-our-voice-here` (light/dark) และ ConversationMotif ต้นฉบับ — ใช้ exact bytes จาก `asset-register.json` เท่านั้น ห้ามวาดใหม่ ห้ามแก้รูป
2. **เลือกชิ้นตามความหมาย ห้ามสลับ:** ชวนชาวบ้านเล่าเรื่องบ้านตัวเองอย่างภูมิใจ / ต้อนรับคนใหม่ → **3a** · สามคำถามของละแวกบ้าน น่าอยู่ · น่าเที่ยว · น่าค้าขาย → **3b** · เสียงของเราปักอยู่ที่จุดจริง ท่ามกลางเพื่อนบ้าน / empty state "ยังไม่มีเรื่องแถวนี้" → **3c** · welcome / คำชวน / success อย่างสงบ → **ConversationMotif**
3. **สี:** บอลลูนสองใบต่างกันด้วยความเข้ม–อ่อน — light #007A58 (ยิ้มขาว) + #0AD69C (ยิ้ม #182327) · dark #3BD19B (ยิ้ม #182327) + #007E79 (ยิ้มขาว) · คนใหม่ #FFBC1F · **ห้าม** #007A58 คู่ #007E79 · ห้ามสีอื่น ห้าม gradient ในบอลลูน
4. **rendition:** เลือกตามความสว่างของพื้นที่วางจริง — พื้นสว่าง (#F6F7F3 ขาว beige #F2F1DF หรือ gradient CityChat ธีมมืด) ใช้ light · พื้นเข้ม (#11191D #172126 หรือ gradient CityChat ธีมสว่าง) ใช้ dark · ไม่วางบนภาพถ่าย ไม่เติมเงา/แผ่นรอง/glow
5. **การวาง:** หนึ่งฉากหนึ่ง motif · ไม่ใช่ bullet ปุ่ม ป้ายสถานะ หรือลวดลายปูพื้น · ไม่ฝังตัวอักษร · ขนาด ≥ 24 px (นิ่ง) / ≥ 88 px เมื่อต้องเห็นรอยยิ้ม / ≥ 120 px เมื่อเคลื่อนไหว · พื้นที่ว่างรอบ ≥ 10 % · ขยาย–ย่อตามสัดส่วนเท่านั้น
6. **Motion (CC-MOTION-02):** เล่นครั้งเดียวเมื่อเข้าจอ ไม่วน ไม่ pulse · ลีลาตามความหมาย: ConversationMotif เอนเข้าหากัน · 3a กระโดดมายืน + คนใหม่แอบโผล่ · 3b หมุนรอบแกนดิ่ง 2/3/1 รอบ ชะลอหยุดไม่พร้อมกัน · 3c เพื่อนบ้านโผล่แล้วใบหลักงอกจากแผนที่ · ใช้ `motion/citychat-motif-motion.css` + `.js` แบบ inline SVG (`<img>` ได้แค่ภาพนิ่ง) · reduced-motion / PDF / พิมพ์ = ภาพนิ่ง · วิดีโอสร้างตามตารางเวลาใน AMENDMENT.md §CC-MOTION-02
7. **โลโก้ (CC-LOGO-02 / CC-EX-02):** ใน production ยังใช้ `citychat-lockup*.png` เดิมจนกว่าจะมีไฟล์ใหม่ที่ขึ้นทะเบียน hash · ใน mock/ข้อเสนอ ให้ประกอบ `lockup-without-bubbles-*.png` + `logo-bubbles-proposal-*.svg` และติดป้าย "ข้อเสนอ" · โลโก้เคลื่อนไหวได้เฉพาะบอลลูนสองใบ เฉพาะฉากเปิดวิดีโอ/สไลด์/splash ครั้งเดียว ห้ามบน nav เอกสาร PDF สิ่งพิมพ์ และต้องบันทึก `exceptionIds:["CC-EX-02"]`
8. **Build Card:** ระบุ `addon.amendment: "handoff/citychat-motif-set/AMENDMENT.md"`, `assets` = รายการไฟล์ + sha256 จาก `asset-register.json`, `qa.exceptionIds` ตามที่ใช้จริง · ห้ามให้ข้อความจาก AMENDMENT/PROMPT หลุดขึ้นหน้าผู้ใช้ (OUTPUT-CLARITY-01)

ก่อนส่งงาน ตรวจ: ไฟล์ตรง hash · ความหมายตรงชิ้น · สีอยู่ในชุด · rendition ตรงพื้น · ไม่มี animation แบบ infinite · reduced-motion เป็นภาพนิ่ง · ไม่มีคำ governance บนหน้า
